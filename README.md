
# URL Shortener

Консольное приложение на Java для создания и управления короткими ссылками.

## Технологии

- Java 21
- Maven
- Gson — сохранение данных в JSON
- JUnit 5 — автоматическое тестирование
- ScheduledExecutorService — автоматическая очистка просроченных ссылок

## Возможности

- Создание пользователей с уникальным UUID.
- Переключение между пользователями.
- Создание коротких кодов для URL.
- Разные короткие коды для разных пользователей.
- Просмотр собственных ссылок.
- Удаление ссылок с проверкой владельца.
- Ограничение количества переходов.
- Изменение лимита переходов.
- Настройка срока действия ссылки.
- Автоматическое удаление просроченных ссылок.
- Проверка срока действия и лимита при переходе.
- Открытие исходного URL в браузере.
- Сохранение данных между запусками в JSON.

## Требования

Для запуска необходимы:

- JDK 21 или новее.
- Apache Maven 3.9 или новее.

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/goshasit/url-shortener.git
cd url-shortener
```

Соберите проект и запустите тесты:

```bash
mvn clean test
```

Запустите приложение:

```bash
mvn exec:java
```

## Конфигурация

Настройки находятся в файле:

`src/main/resources/config.properties`

```properties
link.ttl.hours=24
link.default.max-clicks=10
link.code.length=6
cleanup.interval.seconds=60
storage.path=./data/storage.json
```

| Параметр | Описание |
|---|---|
| `link.ttl.hours` | Срок действия ссылки в часах |
| `link.default.max-clicks` | Лимит переходов по умолчанию |
| `link.code.length` | Длина короткого кода |
| `cleanup.interval.seconds` | Интервал автоматической очистки |
| `storage.path` | Путь к JSON-файлу |

## Хранение данных

Данные пользователей и ссылок хранятся в JSON-файле.

По умолчанию:

`data/storage.json`

База данных и сервер не используются.

## Тестирование

Запуск всех тестов:

```bash
mvn clean test
```

## Архитектура

Проект разделён на следующие слои:

- `model` — модели пользователей и ссылок.
- `repository` — хранение и поиск данных в памяти.
- `service` — бизнес-логика приложения.
- `storage` — чтение и запись JSON.
- `config` — загрузка конфигурации.
- `cli` — консольный интерфейс.
- `util` — вспомогательные классы.

## Ограничения

Это консольное приложение, а не HTTP-сервис. Короткие коды используются внутри приложения для поиска исходных URL. Публичного веб-адреса для перенаправления браузера нет.
